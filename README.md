## 🔬 Research

### Data Flow Control · Columbia DAPLab
A policy-enforcement framework for LLM coding agents that deterministically blocks tool calls and shell commands that violate user-defined data flow rules. I built a Python pipeline that parses and classifies 2,000+ shell commands from SWE-bench Pro agent trajectories, and benchmark the framework's effect on resolve rate using AWS Bedrock and Docker.

### Next-Edit Prediction for Code Completion · MSDS Capstone with IBM
Building datasets, evaluations, and models that predict a developer's next edit, extending Zed's Zeta edit-prediction work.

## 🚀 Projects

### [StatIt](https://github.com/colettak16/StatIt)
Full-stack natural language to SQL engine for NFL player-tracking data.  
`React` `FastAPI` `PostgreSQL` `Claude API`

### Promptly 🏆 Winner, AWS x AGI House Small Language Model Hackathon (Nov 2025)
In-line Chrome extension that reads what you type into an LLM chatbot and suggests ways to make the prompt more effective, powered by a LoRA fine-tuned TinyLlama trained on AWS Trainium.  
`TinyLlama` `LoRA` `AWS Trainium` `Chrome Extension`

### [Aura](https://github.com/colettak16/aura-therapy-chat)
Free, publicly accessible therapy chatbot. Fine-tuned on paired preferred and rejected therapist responses to learn what makes a good reply across five dimensions of therapeutic quality, then served from a Hugging Face inference endpoint behind a web app on Render. [Live demo](https://aura-therapy-chat.onrender.com/) (currently running a fallback model to keep hosting free).  
`Hugging Face` `LoRA` `Python` `Render`

### [ColettaBot](https://kylecoletta.com)
RAG chatbot on my portfolio site that answers questions about my background and projects.  
`OpenAI Embeddings` `Supabase pgvector` `Claude API`

### [AWS x NFL Big Data Bowl](https://github.com/colettak16/AWSxNFL-Big-Data-Bowl)
Competition submission analyzing NFL player-tracking data, with visualizations published as a Quarto site on GitHub Pages.
